# 공개일 Attention 모델

이번 검증에서는 기존 모델보다 좋아지지 않았습니다. 동일 D25~D30 공식 벌점은 기존 246,673.0, Attention 단독 247,808.333, 고정 50:50 앙상블 246,714.667입니다. 앙상블은 기존보다 약 0.017% 높습니다. 새 B 제출 파일은 454대이며 공식 형식 검사를 통과했습니다. 기존 D24 제출은 474대입니다. B 전체 점수는 미공개이므로 이 새 파일이 더 좋은 제출이라고 단정할 수 없습니다. 검증 근거로는 기존 제출을 우선 권장합니다.

추가 N 벌점 없이 공식 식 `20*N + 6*Q + 5*O + E`를 사용합니다.

각 공개일의 24시간 순유입·누적 순유입·절댓값과 날짜별 기상을 각각 인코딩합니다. 예측일의 날짜·기상·대여소 특성으로 공개일 Attention을 계산하고, 공개일의 초기 재고별 한계비용을 가중 결합합니다. 학습된 기본 비용과 공개일 비용을 게이트로 결합하고 잔차를 예측합니다.

공개일 개수를 2~4개로 바꾸며 학습합니다. 절반의 학습 에피소드는 화·수요일 공개 관측만 제공합니다. 각 타깃 날짜의 정답은 해당 에피소드 공개일에서 제외합니다. Attention 입력은 날짜 정보가 포함된 집합이므로 공개일 행 순서에 영향을 받지 않습니다.

외부 검증: A 대여소 5분할, D01~D23의 다른 대여소로 학습하고 공개일 D09·D10·D23·D24만 제공하여 D25~D30 평가. 학습 회수는 내부의 별도 대여소와 D18~D23으로 선택하며 외부 D25~D30 정답은 사용하지 않습니다. 내부 공개일은 D09·D10·D16·D17이고 내부 학습 날짜는 D01~D17입니다.

제출 정책은 검증 전에 고정한 기존 D24 모델 50% + Attention 50%의 한계비용 앙상블입니다. 단독 Attention 성적도 별도 기록합니다. 최종 모델은 A의 전체 30일로 재학습하며, 공개된 B 네 날짜는 실측 비용으로 대체합니다. 배치 최적화는 일별 총량이 동일한 정수 동적계획법을 사용합니다.

실행:
```
python bike_context_attention.py train
python bike_context_attention.py predict
python test_context_attention.py
```

기본 입력은 이 폴더의 기존 A/B Excel, `공개일_D24추가_입력` CSV와 `신경망_공개일D24추가_결과/public_update_model.pt`입니다. `--data-dir`, `--public-dir`, `--baseline-dir`, `--output-dir`로 경로를 지정할 수 있습니다. 기존 Python 의존성을 재사용합니다. 코드 원본과 과거 결과는 덮어쓰지 않습니다.

`신경망_Attention_결과/attention_model.pt`에 새 신경망과 기존 신경망을 함께 저장합니다. `A_validation.json`에서 기존·단독·앙상블 공식 벌점을 확인할 수 있습니다. B 공개일 점수는 입력으로 사용한 데이터의 성적이며, 미공개 날짜의 성능을 보장하지 않습니다. 검증일이 적고 학습 도시가 하나이므로 도시 이동과 주말 예측에는 불확실성이 남습니다.

Git 실행: `python code/demand_neural_final/bike_context_attention.py train` 또는 `predict`. 입력은 저장소 루트의 기존 CSV와 `open_data`, 결과는 `code/demand_neural_final/results_attention/`입니다. 학습에는 기존 `results_public_d24/public_update_model.pt`와 A 검증 캐시가 필요합니다. 제공 ZIP에는 원본 Excel 경로로 실행하는 코드와 필요한 입력·모델이 포함됩니다.
