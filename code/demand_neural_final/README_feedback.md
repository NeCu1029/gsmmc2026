# 제출 결과 집계값을 반영한 배치 개선

제출용 파일은 `제출결과_피드백개선_결과/최종제출_배치표_B지역_피드백개선.csv`입니다. 159개 대여소, D01~D30, 매일 **427대**입니다. 이전 제출은 463대, 서버 벌점 118,428.6이었습니다. 새 배치의 전체 서버 점수는 아직 모릅니다.

## 바뀐 방법

추가 자료를 받지 않고 기존 A 전체 자료, B 입력 자료, 공개 D09·D10·D13·D23·D24, 이번 제출 화면의 날짜별 U/Q/O/E만 사용했습니다. 기존 신경망 코드와 463대 결과는 보존했습니다. 이번 제출은 신경망의 비용 출력을 그대로 쓰는 대신, 실제 대여·반납 경로를 재생하는 시나리오와 집계값 보정을 사용합니다.

1. 공개 순유입 경로·재고 비용 곡선·대여소 환경이 비슷한 A 대여소 32곳을 찾습니다. 서로 다른 도시의 원시 좌표는 직접 비교하지 않습니다.
2. A의 날짜별·시간별 대여/반납 비율로 B의 공개 경로를 해당 날짜의 기상·요일에 맞춰 조정합니다. 평일과 휴일의 공개 경로는 구분합니다. 비율은 0.2~3 범위로 제한합니다.
3. 기존 463대 배치를 이 경로에 넣어 계산한 도시 전체 U/Q/O/E가 화면의 실제 집계값과 비슷해지도록 날짜마다 대여·반납 규모 계수 두 개를 보정합니다. 계수 범위는 0.625~1.6, 정규화 강도는 10입니다. 대여소별 정답을 추정해서 관측값으로 취급하지 않습니다.
4. 보정 전후의 물리적 재고 비용을 1:1로 평균합니다. 공개된 다섯 날짜는 실제 기록에서 구한 비용으로 대체합니다.
5. 모든 정수 재고에 대한 비용을 계산하고, 공식 목적함수 `20*N + 6*Q + 5*O + E`와 매일 같은 N 조건에서 동적 계획법으로 N과 배치를 함께 결정합니다. **추가 N 벌점·N 상한·경쟁팀 N 목표값은 없습니다.**

기존 신경망 가중치는 통합 체크포인트에 보관하며, 추론할 때 이전 제출 배치를 정확하게 재현하는 데 사용합니다. 새 배치를 생성하는 모델 구성요소는 A 경로 참조 데이터와 보정 설정입니다. 이번 변경을 신경망 재학습으로 표현하지 않습니다.

## 검증과 한계

날짜별 S를 `20*463 + 6*Q + 5*O + E`로 다시 계산하고, 월간 합계 Q=494,290, O=35,341, E=132,612, U=50,254 및 평균 S=118,428.6과 대조했습니다. 공개된 다섯 날짜는 실제 파일로도 집계값을 확인했습니다.

A 대여소를 세 그룹으로 나눠 앞의 두 그룹으로 보정 강도·혼합 비율을 선택하고, 나머지 58개 대여소로 시험했습니다. 시험 대여소의 비공개 정답은 설정 선택의 입력·원본 참조 자료에서 모두 제외했습니다. 시험 조건에서는 공개 5일과 기준 배치의 날짜별 집계값만 제공하고 나머지 25일을 평가했습니다. 기준 배치는 공개일과 A 원본 참조 경로로 생성하며, 시험 날짜의 정답을 보고 만들지 않습니다.

| 검증 | 보정 전 | 보정 후 |
|---|---:|---:|
| A 미사용 대여소, 25일 평균 공식 벌점 | 69,834.84 | 69,820.56 |
| B 공개일 하나씩 가리기, 달력 비율 가중 평균 | 139,364.3 | 139,288.1 |

A 시험 개선은 약 0.020%, B 가림 검증 개선은 약 0.055%로 **작습니다**. A 설정 선택용 두 그룹에서는 보정 전보다 유리하지 않았습니다. 일관되게 큰 개선을 확인한 것은 아닙니다. B 가림 검증은 해당 날짜의 대여소별 기록을 숨기지만, 이미 제공된 기존 배치와 집계 피드백은 사용합니다. 순수한 미관측 수요 예측 시험이나 전체 B 점수의 추정값이 아닙니다. 이 검증으로 설정을 다시 바꾸지 않았습니다.

새 배치의 공개 5일 평균 벌점은 146,707.4로, 이전 배치의 146,629.6보다 약간 높습니다. 모든 날에 같은 N을 쓰므로 공개일 최적 비용과 월 전체 최적 비용은 다를 수 있습니다. 이번 후보가 실제 서버에서 개선되는지는 재제출로 확인해야 합니다. 공개일은 입력 자료이므로 이 평균을 독립 시험 성적으로 사용하지 않습니다.

`relative_objective`는 선택과 관계없는 C(0)를 뺀 비용입니다. 음수여도 이상이 없으며 실제 대회 점수가 아닙니다. 집계값만으로 시간별·대여소별 정답을 식별할 수 없습니다.

## 원본 Excel 버전 실행

Python 3.12 CPU 환경에서 실행했습니다. 기존 `requirements_neural_final.txt`를 설치합니다.

```powershell
python -m pip install -r requirements_neural_final.txt
python run_feedback_refinement.py predict
python verify_feedback_refinement.py
python -m unittest test_feedback_calibration
python check_submission.py "제출결과_피드백개선_결과/최종제출_배치표_B지역_피드백개선.csv"
```

`predict`에는 결과 폴더의 `feedback_refined_model.pt`, `feedback_reference.npz`와 원본 B Excel, 공개 5일 CSV가 필요합니다. ZIP에 모두 포함되어 있습니다. 모델은 공개 입력 값이 체크포인트에 저장된 관측과 같은지 검사합니다. 검증 명령에는 A Excel과 A 시험 배치·검증 JSON도 필요합니다.

```powershell
# A 설정 선택/미사용 대여소 시험, B 가림 검증, 모델 묶음 및 배치 재생성
python run_feedback_refinement.py train
```

`train`에는 A/B Excel, 공개 5일, 기존 `신경망_공개일D13주말추가_결과/public_update_model.pt`와 해당 463대 CSV가 필요합니다. 기존 모델의 가중치를 다시 학습하는 명령은 아닙니다.

## Git version2

Git에는 저장소의 기존 `learn_data/`, `input_data/`, `open_data/`를 읽도록 입력 경로를 맞춘 version2를 추가합니다. 수식과 최적화 코드는 동일하며 원본 Excel 버전은 그대로 남깁니다. 기존 팀원 파일을 덮어쓰지 않습니다.

```powershell
python -m pip install -r code/demand_neural_final/requirements.txt
python code/demand_neural_final/run_feedback_refinement.py predict
python code/demand_neural_final/verify_feedback_refinement.py
```

ZIP의 `제출결과_피드백개선_결과/`를 `code/demand_neural_final/results_feedback/`로 복원하면 `predict`가 가능합니다. `train`까지 재현하려면 ZIP의 이전 463대 결과를 `results_public_d13/`로 복원합니다. 루트 `.gitignore`가 `results_feedback/` 전체를 제외하므로 결과 CSV·JSON·PT·NPZ를 커밋하지 않습니다.
