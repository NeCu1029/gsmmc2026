# 허용 벌점 안에서 N 최소화

제출 파일: `code/demand_neural_final/results_bounded/최종제출_배치표_B지역_벌점상한_N최소.csv`

159개 대여소 × D01~D30이며 매일 총 **325대**입니다.
기준인 추가 벌점 없는 515대 배치보다 **190대, 36.89% 감소**했습니다.
공개일 기준 허용 증가율은 **1%**입니다. 전체 B 실제 월 점수에 대한 1% 보장은 아닙니다.

## 기준과 제약식

신경망의 두 종류 비용 예측을 1:1로 평균한 뒤, 다음 두 제약을 만족하는 **가장 작은 정수 N**을 고릅니다.

1. 예측한 월 일평균 벌점 증가량 ≤ 허용 증가량
2. 공개 D09·D10의 실제 평균 벌점 증가량 ≤ 같은 허용 증가량

기준은 기존 515대 모델의 공개 두 날짜 평균 벌점 **165,718.5점**입니다.
허용 증가량은 이 값의 1%인 **1,657.185점**으로 고정합니다.

원래 모델이 예측하는 것은 초기 자전거 한 대 추가의 비용 변화입니다.
초기 재고 0대의 비용 C(0)를 뺀 상대 비용은 음수일 수 있으므로, 상대 비용에 1%를 곱하면 잘못된 상한이 됩니다.
이를 피하기 위해 양수인 실제 공개일 기준 점수로 허용량을 정하고, 예측 비용은 두 배치의 차이로만 비교합니다.
예측 차이에서는 C(0)가 정확히 소거됩니다.

이 제약식에 대한 모든 N의 최선 배치 비용을 DP로 계산하고, 두 상한을 만족하는 가장 작은 N을 선택합니다.
모든 날짜의 총량은 같고, 대여소별 배치는 0 이상의 정수이며 거치대 수 이하여야 합니다.
신경망 가중치는 재사용하고 의사결정층을 제약 최적화로 바꿨습니다.
이번 방식에는 추가 αN 벌점을 적용하지 않습니다. 공식 식은 `20*N + 6*Q + 5*O + E` 그대로입니다.

## 결과

| 항목 | 기준 515대 | 최종 325대 |
|---|---:|---:|
| 공개 두 날짜 실제 평균 벌점 | 165,718.5 | 167,361.0 |
| 공개일 기준 실제 증가율 | 0% | **0.9911%** |
| 예측한 월 일평균 벌점 증가량 | 0 | 922.852 |
| 허용 일평균 증가량 | 0 | 1,657.185 |

**324대**의 공개 두 날짜 최선 평균 벌점은 **167,377.0점**으로 상한 **167,375.685점**을 초과합니다.
전체 양의 정수 N을 검사했으며, 325대보다 작은 모든 N이 적어도 하나의 제약을 위반함을 확인합니다.
따라서 325대는 선택한 예측 모델과 위 두 제약식에 대한 최소 총량입니다.

A 검증은 같은 대여소 외부 5분할, D24~D30의 기존 OOF 예측을 사용합니다.
각 평가 대여소 그룹의 공개 D09·D10 실제 자료로 허용량을 정하며, 평가 기간 정답으로 허용폭을 선택하지 않습니다.
허용폭 1%는 이번 작업의 기본값으로 고정했고, 검증 점수로 조정하지 않았습니다.

- A 배치 총량: **656 → 422대**
- A 실제 공식 평균 벌점: **262,941.571 → 263,988.857**, 약 **0.3983% 증가**

개발하면서 A 검증을 반복 확인했으므로 독립적인 최종 성능 보장으로 해석하면 안 됩니다.
공개 두 날짜는 모델 입력과 제약식에 사용한 자료입니다. 이 날짜의 상한 준수는 새로운 시험 성적이 아닙니다.
미공개 B 28일의 실제 벌점 및 전체 B 월 점수는 재제출 전에는 알 수 없습니다.
미공개 날짜의 실제 증가율이 1% 안에 든다고 보장하지 않습니다.

## 실행

Python 3.12 CPU 환경에서 재현했습니다. 저장소 루트에서 실행합니다. 기존 learn_data/ 및 input_data/ CSV와 open_data/ 공개일 자료를 읽습니다.

```powershell
python -m pip install -r code/demand_neural_final/requirements.txt
# 제공 통합 모델로 제출 파일 재생성
python code/demand_neural_final/bike_bounded_fleet.py predict
# 기존 신경망 모델에서 제약 정책 구성 및 A 비교 검증
python code/demand_neural_final/bike_bounded_fleet.py build --tolerance 0.01
python code/demand_neural_final/verify_bounded_fleet.py
python code/demand_neural_final/test_bounded_fleet.py -v
python check_submission.py "code/demand_neural_final/results_bounded/최종제출_배치표_B지역_벌점상한_N최소.csv"
```

허용폭은 `predict --tolerance 0.005`처럼 바꿀 수 있습니다. 0.005는 공개일 기준 0.5%입니다.
같은 출력 폴더를 사용하면 제출 CSV가 새 정책의 결과로 갱신됩니다.
`B_tolerance_comparison.csv`에는 0%, 0.5%, 1%, 2%, 5%별 N과 상한 충족 여부가 기록됩니다.
허용폭 0%에서는 기존 515대 배치가 정확히 재현되는지 검사합니다.

`bounded_fleet_model.pt`에 신경망 가중치와 기본 허용폭을 함께 저장했습니다.
`build`는 이전 N 추가 벌점 모델 파일을 신경망 가중치 공급원으로 읽지만 α는 가져오지 않습니다.
공개 D09·D10과 기존 OOF 비용에 맞춘 버전이며, 공개일 구성이 바뀌면 이전 단계의 모델/OOF 검증도 함께 갱신해야 합니다.
모델·CSV·검증 JSON·NPZ는 ZIP으로 제공하고 Git 루트 .gitignore에서 제외합니다.


제공 ZIP의 신경망_벌점상한_결과 모델과 결과를 results_bounded/에 복사하면 predict가 가능합니다. build에는 이전 results_fleet/ 통합 모델 및 results_v2/ OOF 검증 비용이 필요합니다. 결과 파일은 루트 .gitignore로 제외됩니다.
