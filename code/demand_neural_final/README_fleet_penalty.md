# 자전거 수 추가 벌점 모델

제출 파일은 `code/demand_neural_final/results_fleet/최종제출_배치표_B지역_N추가벌점.csv`입니다.
159개 대여소 × D01~D30이며 매일 총 **140대**입니다. 이전 515대보다 **375대, 72.82% 감소**했습니다.

## 아키텍처와 학습 기준

`대여소 환경·공개일 패턴·기상 → 두 종류 신경망의 비용 증분 예측 → 1:1 평균 → N 추가 벌점 DP → 정수 배치`

신경망은 초기 자전거를 한 대 늘릴 때 변하는 부족/초과/재고 벌점을 예측합니다.
이 비용 예측에 대해 아래의 목적함수를 최소화하도록 의사결정층을 바꿨습니다.

`내부 목적 = 예상 공식 벌점 + α*N = (20+α)*N + 예상 이용 벌점`

최종 **α=40**이며 내부적으로 자전거 한 대의 비용을 **60**으로 봅니다.
대회의 공식 채점식은 그대로 `20*N + 6*Q + 5*O + E`입니다.
모든 날짜의 총량 N은 같고, 각 배치는 0 이상의 정수이며 거치대 수 이하여야 합니다.
허용하는 모든 N을 DP로 비교하므로, 선택한 α와 예측 비용에 대한 정수 최적해를 구합니다.

기존 신경망 가중치는 재사용했습니다. 이번에 학습한 부분은 N을 줄이는 의사결정 정책의 α입니다.
정수 DP의 N을 신경망 손실에 단순 추가해 역전파했다고 주장하지 않습니다.
모든 신경망 가중치와 α를 하나의 `fleet_penalty_model.pt`에 함께 저장했습니다.

정책 학습 목표는 `A 실제 공식 벌점 + 20*N`으로 정했습니다. 추가 선호의 무게 20은 대회의 기본 보유 비용과 같은 크기입니다.
예측 비용의 오차를 고려해 α 후보 `5, 10, 20, 40, 80` 중 이 목표가 가장 작은 것을 선택합니다.
신경망이 사용하는 α와 실제 자료로 평가하는 추가 선호의 무게가 다른 이유는, α를 예측 비용에 적용했을 때 원하는 실제 균형을 검증으로 맞추기 때문입니다.
α=0은 기존 모델을 재현하는 비교 기준으로만 사용합니다.

각 외부 대여소 분할에서 학습 대여소를 다시 2:1로 나누고, D01~D16으로 신경망을 맞춘 뒤 제외된 내부 대여소의 D17~D23에서 α를 고릅니다.
외부 대여소의 D24~D30은 α 선택에 사용하지 않습니다. 공개일 D09·D10 입력 조건은 유지합니다.
최종 α는 전체 A 학습 대여소를 사용한 같은 내부 절차로 선택했습니다.
개발 과정에서 A 검증을 반복 사용했으므로 독립적인 최종 성능 보장으로 해석하면 안 됩니다.

## N 감소와 벌점의 교환 관계

| α | 내부 한 대 비용 | B 배치 N | 공개 두 날짜의 공식 평균 벌점 |
|---:|---:|---:|---:|
| 0 | 20 | 515 | 165,718.5 |
| 5 | 25 | 412 | 166,288.5 |
| 10 | 30 | 336 | 167,193.5 |
| 20 | 40 | 225 | 169,359.0 |
| **40** | **60** | **140** | **172,698.5** |
| 80 | 100 | 58 | 178,733.0 |

최종안은 N 감소를 우선하는 결과입니다. 공개 두 날짜의 공식 벌점은 기존 대비 약 **4.21% 증가**했습니다.
전체 B 30일 실제 점수는 재제출 전에는 알 수 없습니다. 공개일 점수는 모델 입력으로 사용한 자료의 점수입니다.

A의 같은 외부 예측에 α=40을 일괄 적용하면 공식 벌점은 **262,941.571 → 267,823.429**, 약 **1.86% 증가**하고 N은 **656 → 246**입니다.
각 외부 분할의 내부 검증에서 α를 따로 고르는 전체 정책의 검증은 N **354**, 공식 벌점 **266,575.286**입니다.
두 수치는 각각 고정 α 비교와 α 선택 절차 검증으로 범위가 다릅니다.
추가 벌점까지 포함한 정책 목표와 원래 대회 점수는 `A_validation.json`에 구분해서 기록합니다.

`relative_objective`는 비용 상수 C(0)를 뺀 값입니다. 실제 또는 예상 대회 점수로 읽으면 안 됩니다.

## 실행

Python 3.12 CPU 환경에서 실행했습니다. 저장소 루트에서 실행합니다. 기존 learn_data/와 input_data/의 CSV 및 open_data/를 읽습니다.

```powershell
python -m pip install -r code/demand_neural_final/requirements.txt
# 제공된 통합 모델로 제출 파일 재생성
python code/demand_neural_final/bike_fleet_penalty.py predict
# A 내부 검증으로 N 의사결정 정책 다시 학습
python code/demand_neural_final/bike_fleet_penalty.py train
python code/demand_neural_final/verify_fleet_penalty.py
python code/demand_neural_final/test_fleet_penalty.py -v
python check_submission.py "code/demand_neural_final/results_fleet/최종제출_배치표_B지역_N추가벌점.csv"
```

수동으로 강도를 바꾸려면 별도 출력 폴더를 지정할 수 있습니다.

```powershell
python code/demand_neural_final/bike_fleet_penalty.py predict --alpha 20 --output-dir "다른정책"
```

이 경우 먼저 제공된 `fleet_penalty_model.pt`를 그 출력 폴더에 복사해야 합니다.
`--alpha`가 커지면 같은 예측 비용에서 N은 늘어나지 않습니다. 부족 벌점 증가와 함께 비교해야 합니다.
정책의 학습 목표 자체를 바꾸려면 `train --policy-weight 40`처럼 설정합니다. 새 결과는 별도 폴더에 생성하는 것이 좋습니다.

처음부터 신경망을 다시 학습하려면 이전 단계의 `run_neural_v2.py train`으로 신경망 및 OOF 검증 비용을 먼저 생성합니다.
기존 원본과 결과는 보존했으며, Git에는 새 코드와 루트 `.gitignore`만 반영합니다.
학습 모델, 결과 CSV/JSON/NPZ는 ZIP으로 제공하고 Git에서는 제외합니다.


ZIP의 신경망_N벌점_결과 폴더 파일은 results_fleet/에 복사합니다. 제공 통합 모델만 있으면 predict가 가능합니다. 정책을 재학습하려면 이전 단계의 모델·검증 비용을 각각 results/와 results_v2/에 복원하거나 run_neural_v2.py train을 먼저 실행합니다. 결과는 루트 .gitignore에서 모두 제외됩니다.
