# 마지막 제출 후보: 실제 점수로 보정한 앙상블

최종 제출 파일은 `마지막제출_앙상블_결과/최종제출_B지역_마지막.csv`입니다. **159개 대여소 × D01~D30, 매일 444대**입니다. 추가 N 벌점은 없으며 공식 목적함수 `20*N + 6*Q + 5*O + E`를 사용합니다.

## 이번에 활용한 정보

기존 A/B 입력과 공개 D09·D10·D13·D23·D24, 기존 제출 화면의 날짜별 집계값을 사용합니다. 새 공개일 자료는 받지 않았습니다. 추가로 사용자가 확인한 **427대 제출 점수 118,429.0**을 반영했습니다.

| 이미 제출한 배치 | 실제 전체 서버 벌점 |
|---|---:|
| 신경망 기반 463대 | 118,428.6 |
| 시나리오 기반 427대 | 118,429.0 |

463대 배치의 날짜별 정수 벌점 합으로 복원한 평균은 118,428.5666667입니다. 427대는 소수점 한 자리 표시값을 사용했습니다. 두 결과는 사실상 동률입니다.

## 모델과 배치가 바뀐 방식

기존 신경망은 427대 배치가 463대보다 약 1,541점 나쁘다고 예측했고, 물리적 경로 시나리오 모델은 약 1,331점 좋다고 예측했습니다. 실제 차이는 약 0.43점입니다. 이 차이와 맞도록 **하나의 앙상블 비중만** 추정했습니다.

`C = (1-w)*C_neural + w*C_scenario`, `w = 0.5364306227`

따라서 신경망 약 46.36%, 시나리오 약 53.64%를 사용합니다. C(0)를 뺀 상대 비용을 사용하지만, 두 배치의 점수 차이에서는 이 상수가 소거됩니다. 자전거 가격 계수 20은 그대로입니다. 앙상블 비중 보정은 신경망 가중치 재학습과 구분합니다.

마지막 제출의 위험을 줄이기 위해 **미공개 날짜의 각 대여소 재고를 기존 두 제출안의 해당 재고 사이로 제한**했습니다. 전체 N을 특정 수치나 구간으로 강제한 것은 아닙니다. 공개된 다섯 날짜는 재고별 실제 비용을 알기 때문에 이 제한을 풀고, 선택한 N에서 거치대 범위 전체를 최적화합니다. 날짜마다 동일한 N을 쓰는 조건에서 정수 동적 계획법으로 최종 444대와 배치를 결정했습니다.

## 검증

두 제출안의 점수를 입력으로 보정하는 과정을 A에서 재현했습니다. 대여소를 다섯 그룹으로 나누고, 평가 대여소의 개별 비공개 기록을 학습 입력에서 제외했습니다. 다른 A 대여소는 원래 B 예측에서 전체 A 월 자료를 쓰는 조건에 맞춰 D01~D30을 학습했습니다. 학습 횟수와 기존 신경망 설정은 고정했습니다. 평가 대여소는 공개 5일, 기준 배치의 집계 피드백, 두 기준 배치의 전체 점수만 제공합니다. 새 배치의 정답으로 비중이나 설정을 바꾸지 않았습니다.

| A 평가 | 신경망 기준 | 시나리오 기준 | 최종 방식 |
|---|---:|---:|---:|
| 전체 30일 | 231,625.067 | 231,655.067 | **231,435.833** |
| 공개일을 제외한 25일 | 223,390.48 | 223,429.40 | **223,162.36** |

미공개 25일에서 신경망 기준보다 약 **0.102%** 감소했습니다. 별도로 원래 D25~D30 예측 캐시를 사용한 검증에서도 246,163.167 → 245,840.167로 감소했습니다. 두 시험의 학습 기간·평가 기간이 다르므로 시험 사이의 점수를 직접 비교하지 않습니다.

한 달 검증에서 각 그룹의 두 기존 후보 중 더 좋은 후보까지 이긴 것은 **2/5그룹**입니다. 평균은 개선됐지만 모든 그룹에서 좋아진 것은 아닙니다. 제한을 없앤 후보보다 한 달 평균 벌점이 낮아서, 사전에 정한 제한 방식을 최종으로 유지했습니다. A는 개발 과정에서 반복 사용한 자료이고, 위 평가는 집계 피드백이 주어진 배치 개선 시험입니다. 일반적인 무관측 수요 예측 성능이나 새 B 서버 점수로 해석하면 안 됩니다.

444대의 공개 5일 평균 벌점은 146,659.8입니다. 이 날짜들은 입력에 사용됐고, 평일 비중이 높으므로 전체 B 월 점수의 추정값이 아닙니다. 새 배치의 실제 전체 서버 점수는 아직 모릅니다. JSON의 예상 변화량 역시 모델 추정값이며 실제 달성 점수가 아닙니다.

형식 검사, 거치대 상한·음수·정수·매일 동일 N 검사, 공식 채점기 대조, 저장 모델에서 배치 재생성을 확인했습니다. 118,429.0으로 반올림되는 가능한 실제 월 점수 세 가지를 모두 넣어도 최종 배치 4,770개 셀이 동일했습니다.

## 원본 Excel 버전

```powershell
python -m pip install -r requirements_neural_final.txt
# 저장된 최종 모델에서 제출 파일 재생성
python run_last_submission.py predict
python verify_last_submission.py
python -m unittest test_score_consensus
python check_submission.py "마지막제출_앙상블_결과/최종제출_B지역_마지막.csv"
```

`predict`에는 `마지막제출_앙상블_결과/consensus_model.npz`, 원본 B Excel, 공개 5일이 필요합니다. 모델은 대여소·달력·기상 입력과 공개 관측이 저장 시점과 같은지 검사합니다. ZIP에는 필요한 원본 코드·입력·모델·검증 결과를 포함했습니다.

```powershell
# 기존 두 모델의 비용과 제출안을 다시 묶어 최종 앙상블 생성
python run_last_submission.py build
# 기존 D25~D30 예측 캐시 기반 검증
python run_last_submission.py validate
# 전체 월 자료로 다른 대여소를 학습하는 5분할 검증
python validate_last_full_month.py
```

`build`는 이전 두 결과 폴더의 CSV와 `B_feedback_costs.npz`를 읽습니다. 검증에는 A Excel과 463대 결과 폴더의 모델·A 검증 설정·예측 캐시도 필요합니다. 기존 코드와 이전 결과는 그대로 보존했습니다.

## Git용 version2

저장소에서는 기존 `learn_data/`, `input_data/`, `open_data/` CSV를 읽습니다. 새 코드의 수식·최적화는 원본과 동일하며 경로만 조정했습니다. 팀원의 기존 파일을 덮어쓰지 않고 새 실행 파일을 추가했습니다.

```powershell
python -m pip install -r code/demand_neural_final/requirements.txt
python code/demand_neural_final/run_last_submission.py predict
python code/demand_neural_final/verify_last_submission.py
```

ZIP의 `version2/`는 이 배치의 재현에 필요한 CSV 입력과 코드·모델을 포함합니다. 최종 산출물 위치는 `code/demand_neural_final/results_last/`이며, 루트 `.gitignore`가 결과 CSV·JSON·NPZ 등 전체 실행 산출물을 제외합니다. 모델과 결과 파일은 Git 대신 제공 ZIP에서 받습니다.
