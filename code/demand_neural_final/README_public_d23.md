# 기존 신경망 앙상블에 D23 공개일 추가

제출 파일: `code/demand_neural_final/results_public_d23/최종제출_배치표_B지역_D23추가.csv`

159개 대여소 × D01~D30, 매일 총 **483대**입니다.
기준은 N 추가 벌점 실험 전의 **515대, 1:1 신경망 앙상블**입니다.
공식 목적함수 `20*N + 6*Q + 5*O + E`로 배치합니다. 추가 αN과 벌점 상한은 적용하지 않습니다.

## 반영한 내용

기존 D09·D10에 새로 받은 `B지역_공개일_D23_2026-06-23.csv`를 추가했습니다.
세 날짜 모두 159개 대여소 × 24시간의 유일한 키와 음수 없는 정수 대여·반납 값을 검사했습니다.

- 기존 비용 신경망의 공개일 오차 보정: 공개 두 날짜 평균에서 세 날짜 평균으로 갱신
- 공개일 패턴 신경망: 시간별 순유입 평균·변동성·누적 패턴과 재고별 기준 비용을 세 날짜로 갱신
- 공개 D09·D10·D23: 실제 기록에서 계산한 재고별 비용 사용

신경망 가중치, 정규화 버퍼, 기존 보정 계수, 시드, 신경망 혼합 비율은 보존했습니다.
새 통합 모델에 저장된 모든 신경망 텐서가 원래 체크포인트와 정확히 같음을 검사합니다.
기존 체크포인트의 학습 공개일 메타데이터 D09·D10을 D23까지 학습한 것처럼 바꾸지 않았습니다.
학습 당시 공개일과 현재 추론에 사용할 공개일을 별도로 기록합니다.

이 추가 반영은 고정된 모델의 추론 입력을 갱신하는 과정입니다.
따라서 이전 학습 코드의 내부 검증 기간을 D23에 맞춰 바꾸거나, 기존 신경망 구조를 수정하지 않았습니다.
통합 모델 파일은 `public_update_model.pt`입니다.

## 검증

동일한 A 대여소 외부 5분할과 D24~D30 평가를 유지했습니다.
기존 외부 검증 모델을 원래 두 공개일과 원래 학습 설정으로 결정적으로 복원하고,
기존 예측을 정확히 재현하는지 확인한 다음, 제외된 대여소의 공개 D23만 추가로 입력했습니다.
최종 B 모델에는 처음 저장한 신경망 가중치를 그대로 사용합니다.

| A 검증 | 기존 공개 D09·D10 | D23 추가 |
|---|---:|---:|
| 하루 평균 공식 벌점 | 262,941.571 | **261,224.857** |
| 평가 대여소 전체 총량 | 656 | 661 |

같은 조건의 A 검증 벌점은 약 **0.653% 감소**했습니다.
개발 과정에서 A 검증을 반복 사용했으므로 독립적인 최종 성능 보장은 아닙니다.
D24~D30의 정답은 공개일 추가 입력에 사용하지 않습니다.

| B 공개일 실제 벌점 | 기존 515대 | 새 483대 |
|---|---:|---:|
| D09 | 176,575 | 176,651 |
| D10 | 154,862 | 154,963 |
| D23 | 189,868 | **184,467** |
| 세 날짜 평균 | 173,768.333 | **172,027.000** |

공개일은 모델 구성에 이용한 자료이므로 이 점수는 별도의 테스트 점수가 아닙니다.
미공개 날짜를 포함한 전체 B 성적은 재제출 후 확인해야 합니다.
`relative_objective`는 C(0)를 뺀 상대 비용으로, 전체 대회 점수의 예측값이 아닙니다.

## 실행

Python 3.12 CPU 환경에서 실행했습니다. 저장소 루트에서 실행합니다. 기존 learn_data/와 input_data/ CSV 및 open_data/ 공개일 자료를 읽습니다.

```powershell
python -m pip install -r code/demand_neural_final/requirements.txt
# 제공된 통합 모델로 제출 파일 재생성
python code/demand_neural_final/update_public_ensemble.py predict
# 기존 모델을 묶고, 세 공개일 반영 및 A 비교 검증을 재실행
python code/demand_neural_final/update_public_ensemble.py build
python code/demand_neural_final/verify_public_update.py
python code/demand_neural_final/test_public_update.py -v
python check_submission.py "code/demand_neural_final/results_public_d23/최종제출_배치표_B지역_D23추가.csv"
```

추가 자료는 `공개일_D23추가_입력/`에 보관합니다. 이 버전은 D09·D10·D23에 맞춰 검증했습니다.
D24~D30 내부의 날짜가 새로 공개되면 평가 기간과 비교 검증을 먼저 조정해야 합니다.
기존 파일은 보존했고, Git용 버전에서는 기본 입력 경로만 기존 저장소 CSV로 바꿉니다.
모델과 결과는 루트 .gitignore에서 제외하고 ZIP으로 제공합니다. D23 입력 CSV는 open_data/에 추가합니다.


제공 ZIP의 신경망_공개일D23추가_결과는 results_public_d23/에 복사합니다. build/검증에는 원래 모델과 OOF 비용을 각각 results/ 및 results_v2/에 복원해야 합니다.
open_data/에 D23이 추가된 상태에서는 위 새 실행 명령을 사용합니다. 이전 두 공개일 전용 predict는 공개일 집합이 달라지면 중단하도록 되어 있습니다.
